# Steps for "Run steps.bat": one command per line, run top to bottom against the tablet. Lines starting with # are skipped.
# Results land in reports\steps (cleared at the start of every run).
#
#   DEVICE wifi|usb        which connection to use
#   INSTALL                install the newest Drehzahl APK from the apk folder (or the GitHub release)
#   HELPER                 start the Wi-Fi helper (needed again after every tablet restart)
#   SHELL <command>        run a command on the tablet
#   SAVE <name> <command>  run a command and save its output to reports\steps\<name>.txt
#   SHOT <name>            save a screenshot to reports\steps\<name>.png
#   PUSH / PULL            copy a file to or from the tablet
#   OBDLOG, LOGCAT         save Drehzahl's OBD2 log or the tablet log
#   WAIT <seconds>
#
# Do not put double quotes inside SHELL or SAVE commands: Windows removes them.
#
# Example: install the newest build, start the helper and save what the tablet is.
DEVICE wifi
INSTALL
HELPER
SAVE tablet getprop ro.product.model; getprop ro.build.version.release
SAVE drehzahl dumpsys package dev.kelton.drehzahl | grep -E versionName
SHOT home
